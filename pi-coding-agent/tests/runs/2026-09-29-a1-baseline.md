## Transcript (the agent's final report, verbatim)

**Answer:** Pi has three ways to set a custom system prompt. I checked each against the Pi 0.99.1 docs and `pi --help`. I did not run a live prompt through a model.

1. **Command-line flags** (per run):
   - `pi --system-prompt <text|path>` replaces the default coding-assistant prompt. It takes literal text or the path of an existing file.
   - `pi --append-system-prompt <text|path>` adds to the default prompt instead of replacing it. You can repeat it, e.g. `pi --append-system-prompt ./instructions.md`.
2. **Files** (saved):
   - `<agent-dir>/SYSTEM.md` replaces the default prompt for every project. `<agent-dir>` defaults to `~/.pi/agent`, and `PI_CODING_AGENT_DIR` overrides it.
   - `<agent-dir>/APPEND_SYSTEM.md` appends to the default prompt.
   - `.pi/SYSTEM.md` and `.pi/APPEND_SYSTEM.md` in the project do the same for that project only. They load only after project trust is granted.
   - A trusted project file takes precedence over the same-named file in the agent directory. The two are not combined.
   - Run `/reload` after editing these files in an interactive session.
3. **Extensions:** the `before_agent_start` event lets an extension change the prompt for a run. Returning `systemPrompt` replaces the whole prompt for that run. The docs prefer changing prompt sections, tools, or guidelines instead.

Separately, `AGENTS.md` and `CLAUDE.md` context files add instructions but do not replace the system prompt.
