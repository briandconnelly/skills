**Answer: what is a virtual model in Pi?**
A virtual model is a selectable model that picks a physical model for each request. It lets you route by task, cost or conversation state while the user selects a single model. For example, a router can send quick questions to a small model and hard problems to a large one.

- **Registration:** An extension registers it with `pi.registerVirtualModel({provider, id, name, thinkingLevels, route})`. It can also be registered from SDK code with `modelRuntime.registerVirtualModel`.
- **Where it appears:** It shows up in `/model`, `--model`, scoped models and settings like any other model. It can be listed under any provider, e.g. `openai-codex/auto`.
- **Routing:** `route(request, ctx)` runs before every request. It returns `{model, thinkingLevel}` for a physical model that has credentials. A virtual model cannot route to another virtual model. If `route()` throws or returns an invalid model, the request ends with an error response.
- **Selection versus dispatch:** Pi keeps these apart.
  - Selection is the (virtual model, virtual level) pair. It is recorded in `model_change` and `thinking_level_change` entries.
  - Dispatch is the (physical model, physical level) pair. It is recorded on each assistant message.
  - The virtual thinking level is only an input to the router. Its meaning is up to the router.
  - Providers only receive physical models.
- **Request reasons:** The `request` passed to `route()` includes a `reason`: `user`, `continuation`, `retry` or `direct`. Returning `previous` for `continuation` and `failed` for `retry` keeps prompt caches and thinking signatures valid.
- **Router state:** `route()` can also return JSON `state`. Pi stores it on the session branch and passes it back as `request.state`.
- **Display and limits:** The footer shows the routed model, e.g. `auto • high → gpt-5.6-luna • medium`. `/session` lists cost per physical model. Context and compaction limits use the physical model that answered.
- **Status:** Experimental. The bundled example is `examples/extensions/jev-router.ts`.
